# 隐私说明

> 当前代码核对日期：2026-08-12。本页用于说明当前实现中的数据流，不构成对特定地区法律合规性的完整评估。

* 当前构建未接入 Firebase、广告或其他分析/遥测 SDK，也没有项目运营的账号、内容或崩溃上报服务器。崩溃记录和应用日志默认保存在设备本地，只有用户主动导出、分享时才会离开设备。
* 书架、书源、阅读记录和设置主要保存在设备本地。启用 WebDAV 备份或阅读进度同步后，相关数据会发送到用户自行配置的 WebDAV 服务。
* App 会按用户操作访问书源网站、图片/音视频地址、在线朗读服务、远程书库和更新检查等第三方网络地址。第三方服务可能按其自身规则处理 IP、请求头、账号或请求内容，项目无法替代这些服务作出承诺。
* App 可选启用局域网 Web 服务，供同一网络中的浏览器访问书架和阅读功能。Android 17 上首次开启该功能时，App 会按需请求“附近设备”中的局域网访问权限；这项请求只由用户主动开启 Web 服务触发，用于允许浏览器连接手机上的 HTTP/WebSocket 端口，拒绝或撤销后 Web 服务保持关闭。请只在可信网络中开启，并在不用时关闭。
* `ReaderProvider` 为兼容外部集成而保持导出，但已使用随应用 ID 变化的签名级读写权限保护；只有声明对应权限且与本 App 使用同一签名证书的应用才能访问。具体权限名和调用方式见项目 `api.md`。
* 存储、通知、前台服务、安装包安装等权限只应在对应功能需要时使用。书籍目录、备份目录和外部文件由用户选择或授权；Android 版本不同会影响可用的存储方式。
* App 内置 JavaScript 引擎。用户导入的书源、规则或在线脚本可以发起网络请求并调用允许的扩展能力；请只导入可信规则，并自行承担第三方规则带来的风险。
