# 基类

- Activity：`BaseActivity`、`VMBaseActivity`、`BaseReadActivity`。
- Fragment：`BaseFragment`、`VMBaseFragment`。
- Dialog：`BaseDialogFragment`、`BaseBottomDialogFragment`、`BasePrefDialogFragment`。
- Service：`BaseService`。
- ViewModel：`BaseViewModel`、`BaseReadViewModel`。
- RecyclerView 适配器基类位于 `adapter/`。

新增界面时优先复用与现有同类页面一致的基类，不要仅根据本清单机械选择。
