## 模块结构

```text
app
├── api/           Web/Content Provider 共用控制器与外部接口
├── base/          Activity/Fragment/Service/ViewModel 基类
├── ui/            所有界面，按功能分目录
├── model/         阅读器/朗读/音频等全局业务状态
├── data/          Room 数据库、DAO、Entity
├── help/          配置、书籍处理、ContentProcessor、WebDAV
├── utils/         通用扩展和工具
├── lib/           第三方库封装、自定义 View、Cronet、WebDAV
├── web/           HTTP/WebSocket 服务与 APK Web 静态资源响应
└── assets/web/    APK 内实际加载的 Web UI 产物

modules/book       EPUB 读写库（Android library，minSdk 21）
modules/rhino      Rhino JavaScript 引擎封装（Android library）
modules/web/src    Web 服务浏览器端 Vue 源码（不是 Gradle 子模块）
```

## 核心目录

| 目录 | 用途 |
|------|------|
| `app/src/main/java/io/legado/app/base/` | 基类；多数 Activity 继承 `VMBaseActivity<Binding, ViewModel>` |
| `app/src/main/java/io/legado/app/ui/` | 界面层；阅读页在 `ui/book/read/` |
| `app/src/main/java/io/legado/app/model/` | 全局业务状态；阅读器核心是 `ReadBook.kt` |
| `app/src/main/java/io/legado/app/data/` | Room 数据库；访问入口 `appDb.xxxDao()` |
| `app/src/main/java/io/legado/app/help/` | 配置、书籍处理、WebDAV、ContentProcessor |
| `app/src/main/java/io/legado/app/utils/` | 通用 Kotlin 扩展函数 |
| `app/src/main/java/io/legado/app/lib/` | Cronet/WebDAV/权限/主题等封装 |
| `modules/web/src/` | Web 服务前端源码；唯一生产入口由 `modules/web/index.html` 加载 `main.ts`，旧 `pages/*` 分入口已删除 |
| `app/src/main/assets/web/` | APK 实际加载的 Web UI 资源 |

## 常见修改入口

| 场景 | 入口 |
|------|------|
| 阅读器功能 | `ui/book/read/`, `model/ReadBook.kt`, `help/config/ReadBookConfig.kt` |
| 排版分页 | `ui/book/read/page/provider/TextChapterLayout.kt` |
| 翻页动画 | `ui/book/read/page/delegate/`, `constant/PageAnim.kt`, `ReadStyleDialog.kt` |
| 本地书 TXT/EPUB/UMD/PDF/MOBI/AZW/CBZ | `model/fileBook/`, `help/book/BookHelp.kt`；格式扩展优先实现 `LocalBookFormatHandler` |
| 外部“打开方式”导入本地书 | `ui/association/FileAssociationDialog.kt`, `FileAssociationViewModel.kt`, `utils/LocalBookFileImportHelper.kt`；目标创建、备份、覆盖、校验和回滚必须在同一导入事务内 |
| WebDAV 配置/进度 | `help/AppWebDav.kt`, `lib/webdav/`, `ui/book/import/remote/`；阅读进度调用优先走 `BookProgressSyncProvider` |
| 书源解析 | `modules/rhino/`, `model/webBook/`, `ui/book/source/edit/` |
| 主题外观 | `help/config/ThemeConfig.kt`, `ui/config/ThemeConfigFragment.kt`, `res/values*/` |
| 后台服务 | `service/`, `AndroidManifest.xml`, `utils/ContextExtensions.kt` |
| 数据库 | `data/entities/`, `data/dao/`, `data/AppDatabase.kt` |
