# AI 编辑必看 - 开发规则

> 返回主入口: `../AI编辑必看架构图.md`

---

## 编码规则

- 缩进 4 spaces；命名使用 Kotlin 常规 camelCase/PascalCase。
- Activity 优先继承 `VMBaseActivity<Binding, ViewModel>`；Fragment 用 `BaseFragment()` 或 `BaseDialogFragment()`。
- View 使用 ViewBinding，不新增 `findViewById` 风格代码。
- 数据库访问走 `appDb.xxxDao()`，DB 操作放协程/IO 线程。
- 通用工具放 `utils/`；业务逻辑放对应模块，不在界面层堆 DB/网络细节。
- 兼容旧 API 时按 API level 分支，旧分支局部 `@Suppress("DEPRECATION")`。
- 不用 `GlobalScope` 承接普通业务协程。

## 构建验证

```bash
# 最小 Debug Kotlin 编译验证
scripts/check-debug.sh

# Debug APK
./gradlew :app:assembleDebug --no-daemon

# Release APK（需本地签名配置）
./gradlew :app:assembleRelease --no-daemon
```

注意:

- 本地 Android SDK 在 `.sdk/`。
- Gradle 下载/AGP/split APK 等细节看 `适配踩坑记录.md`。
- 修改数据库后需要跑 KSP 相关任务或完整编译确认生成代码。
