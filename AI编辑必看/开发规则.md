# AI 编辑必看 - 开发规则

> 返回主入口: `../AI编辑必看架构图.md`

---

## 编码规则

- 缩进 4 spaces；命名使用 Kotlin 常规 camelCase/PascalCase。
- 有 ViewModel 的 Activity 优先继承 `VMBaseActivity<Binding, ViewModel>`，无 ViewModel 可用 `BaseActivity<Binding>`；有 ViewModel 的 Fragment 使用 `VMBaseFragment<Binding, ViewModel>`，普通 Fragment/Dialog 使用 `BaseFragment()` / `BaseDialogFragment()`。
- View 使用 ViewBinding，不新增 `findViewById` 风格代码。
- 数据库访问走 `appDb.xxxDao()`；新增或修改的 DB 操作优先放协程/IO 线程。项目仍启用了 `allowMainThreadQueries()` 并保留少量遗留同步查询，不能把“全部已在协程”当成当前事实。
- 通用工具放 `utils/`；业务逻辑放对应模块，不在界面层堆 DB/网络细节。
- 兼容旧 API 时按 API level 分支，旧分支局部 `@Suppress("DEPRECATION")`。
- 不用 `GlobalScope` 承接普通业务协程。

## 构建验证

```bash
# 最小 Debug Kotlin 编译验证
scripts/check-debug.sh

# Debug APK
./gradlew :app:assembleDebug --no-daemon

# 提交前 Release/R8 编译验证（需本地签名配置）
./gradlew :app:assembleRelease --no-daemon

# 最终提交后生成可直接安装的个人签名 Release APK
scripts/build-signed-release.sh

# Web 可复现安装、类型检查与生产构建
cd modules/web
pnpm install --frozen-lockfile
pnpm run type-check
pnpm run build-only
cd ../..
cp modules/web/dist/index.html app/src/main/assets/web/index.html
cp modules/web/dist/favicon.ico app/src/main/assets/web/favicon.ico
cmp -s modules/web/dist/index.html app/src/main/assets/web/index.html
cmp -s modules/web/dist/favicon.ico app/src/main/assets/web/favicon.ico
scripts/check-web-assets-sync.sh
```

注意:

- Gradle 使用的 Android SDK 由 `local.properties` 指定；当前机器指向 `/home/liu/Android/Sdk`。仓库内 `.sdk/build-tools` 主要作为签名校验工具的优先查找位置，不等于 Gradle SDK。
- Gradle 下载/AGP/split APK 等细节看 `适配踩坑记录.md`。
- `scripts/build-signed-release.sh` 要求工作树干净，并只接受 `app/gradle.properties` 与 keystore 权限为 `400` 或 `600`（通常使用 `600`）；脚本校验固定个人证书、五个 APK、包名和版本，再把同批 APK/`.idsig`/metadata 原子同步到 `app/app/release/`。64 位安卓真机优先安装 `legado_arm64.apk`。
- 修改数据库后需要跑 KSP 相关任务或完整编译确认生成代码。
- `modules/web/pnpm-lock.yaml` 是 Web 构建的受控依赖快照；安装必须使用 `--frozen-lockfile`，依赖变更时同步提交 lockfile。
- 本地 `pnpm build`/`build-only` 不会自动复制 assets（`scripts/sync.js` 仅在 GitHub Actions 环境复制）。生产构建后必须手动同步 `index.html` 和 `favicon.ico`，并用 `cmp -s` 确认 `modules/web/dist/` 与 `app/src/main/assets/web/` 字节一致。`scripts/check-web-assets-sync.sh` 是暂存区拦截器，不能单独证明未暂存文件一致。

## 文档维护

- 兼容性/API/构建/运行时适配问题写入 `适配踩坑记录.md`。
- 新功能设计、交互、性能和回归测试写入 `新功能踩坑记录.md`。
- `适配踩坑记录.md` 最多保留 15 条；满 15 条后整体改名归档到 `文档归档/` 并重新开新文件记录，不再来回挪动单条。
- 主入口 `../AI编辑必看架构图.md` 只保留路由和红线；详细内容写入本目录子文件。
- `app/src/main/assets/updateLog.md` 顶部追加 `**YYYY/MM/DD**` 和本次修改摘要；每个日期最多 2 句话，只保留用户需要知道的功能、修复或兼容变化。更新日志不是完整改动清单；依赖升级、构建脚本、验证过程、内部重构和实现细节默认不写。
