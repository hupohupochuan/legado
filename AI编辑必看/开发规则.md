> 返回主入口: `../AI编辑必看架构图.md`

## 编码规则

- 缩进 4 spaces；命名使用 Kotlin 常规 camelCase/PascalCase。
- Activity 优先继承 `VMBaseActivity<Binding, ViewModel>`；Fragment 用 `BaseFragment()` 或 `BaseDialogFragment()`。
- View 使用 ViewBinding，不新增 `findViewById` 风格代码。
- 数据库访问走 `appDb.xxxDao()`，DB 操作放协程/IO 线程。
- 通用工具放 `utils/`；业务逻辑放对应模块，不在界面层堆 DB/网络细节。
- 兼容旧 API 时按 API level 分支，旧分支局部 `@Suppress("DEPRECATION")`。
- 不用 `GlobalScope` 承接普通业务协程。

## 构建验证

```bash
# 最小 Debug Kotlin 编译验证
scripts/check-debug.sh

# Debug APK
./gradlew :app:assembleDebug --no-daemon

# 提交前 Release/R8 编译验证（需本地签名配置）
./gradlew :app:assembleRelease --no-daemon

# 最终提交后生成可直接安装的个人签名 Release APK
scripts/build-signed-release.sh

# Web 可复现安装、类型检查与生产构建
cd modules/web
pnpm install --frozen-lockfile
pnpm run type-check
pnpm run build-only
cd ../..
scripts/check-web-assets-sync.sh
```

注意:

- 本地 Android SDK 在 `.sdk/`。
- Gradle 下载/AGP/split APK 等细节看 `适配踩坑记录.md`。
- `scripts/build-signed-release.sh` 要求工作树干净，并要求 `app/gradle.properties` 与 keystore 权限为 `600`；脚本校验固定个人证书、五个 APK、包名和版本，再把同批 APK/`.idsig`/metadata 原子同步到 `app/app/release/`。64 位安卓真机优先安装 `legado_arm64.apk`。
- 修改数据库后需要跑 KSP 相关任务或完整编译确认生成代码。
- `modules/web/pnpm-lock.yaml` 是 Web 构建的受控依赖快照；安装必须使用 `--frozen-lockfile`，依赖变更时同步提交 lockfile。
- Web 生产构建后必须确认 `modules/web/dist/index.html` 与 `app/src/main/assets/web/index.html` 一致；依赖/类型工具配置变化后产物字节未变时，同步检查允许不制造无意义的 assets diff，运行时源码变化仍必须暂存 assets。

## 文档维护

- 兼容性/API/构建/运行时适配问题写入 `适配踩坑记录.md`。
- 新功能设计、交互、性能和回归测试写入 `新功能踩坑记录.md`。
- `适配踩坑记录.md` 最多保留 15 条；满 15 条后整体改名归档到 `文档归档/` 并重新开新文件记录，不再来回挪动单条。
- 主入口 `../AI编辑必看架构图.md` 只保留路由和红线；详细内容写入本目录子文件。
- `app/src/main/assets/updateLog.md` 顶部追加 `**YYYY/MM/DD**` 和本次修改摘要；摘要必须尽量短，只写用户可感知的变化，不写文件名、实现细节、验证过程或内部回退机制。
